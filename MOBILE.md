# Игра на телефоне

Одиночная игра работает на телефоне: сенсорное управление, вёрстка под узкий
экран и PWA — всё в репозитории и проверено в браузере (`node tests/browser.js`,
21 проверка). Кооператив к этому отношения не имеет, план по нему — в
[COOP.md](COOP.md).

---

## 1. Как поиграть прямо сейчас

Самый быстрый способ — раздать игру с компьютера в ту же сеть, где висит телефон:

```
node tools/server.js
```

Сервер печатает адрес вида `http://192.168.1.5:8123` — его и открыть в браузере
телефона. Телефон и компьютер должны быть в одной сети.

Второй способ — выложить игру на статический хостинг с HTTPS. Репозиторий
публичный, поэтому GitHub Pages бесплатны и настраиваются в три клика:

Pages придётся включить один раз руками — **из workflow это невозможно**.
Пробовали: `actions/configure-pages` с `enablement: true` получает от GitHub
«Create Pages site failed: Resource not accessible by integration», у токена
Actions нет права создавать сайт.

Один клик, дальше всё само:

**Settings → Pages → Source: `GitHub Actions` → Save.**

После этого `.github/workflows/pages.yml` на каждый пуш в ветку прогоняет
`tests/run.js`, собирает папку через `make-webdir.js --pwa` и выкладывает её на
`https://keepi1real.github.io/my2game228/`. На страницу идёт только игра —
`tests`, `tools` и `.git` туда не попадают.

Вариант без workflow: **Source: `Deploy from a branch` → Branch:
`claude/lotr-2d-game-dev-gatk6f`, папка `/ (root)`.** Тогда публикуется весь
репозиторий как есть; собирать всё равно ничего не нужно, потому что
`index.html` лежит в корне, а пути в коде относительные — раздача из подпапки
проверена, service worker получает scope `/my2game228/`.

Тогда Chrome предложит «Установить приложение», и игра появится на рабочем
столе отдельной иконкой, без адресной строки и с работой без сети.

Пустой файл `.nojekyll` в корне отключает обработку Jekyll: ломать ему тут
нечего, но он молча пропускает файлы, начинающиеся с подчёркивания, и замедляет
выкладку.

**HTTPS обязателен для установки и офлайна.** Service worker по `http://` не
регистрируется нигде, кроме `localhost`. По локальной сети игра откроется и
будет играбельна, но останется вкладкой браузера.

## 2. Управление пальцем

Слой включается сам при первом касании экрана. До этого мышь и клавиатура
работают как раньше — на настольной машине ничего не меняется.

| | Действие |
|---|---|
| Палец на левой половине | плавающий стик движения: кольцо появляется там, где палец опустился |
| Протяжка по правой половине | ручной прицел |
| ⚔ большая кнопка | атака; пока палец лежит — бьём непрерывно |
| ⇢ | уклонение |
| Три круга по дуге | умения 1–3, с откатом на кольце |
| Ряд внизу | расходники |
| ⚖ | торговец, всплывает только рядом с ним |
| ☰ и ❙❙ | сумка и пауза |

**Прицел наводится сам** на ближайшего видимого врага в радиусе 420 px и
доводится плавно. Это не поблажка, а необходимость: пальцем целиться некогда,
а без прицела не играются ни Фаелас, ни Митрандир — половина героев. Тот же
приём стоит и за
[мобильными рогаликами вроде Soul Knight](https://minireview.io/action/soul-knight/games-like).
Кому мешает — протяжка по правой половине перебивает автонаведение.

Стик аналоговый: чем ближе палец к центру кольца, тем медленнее шаг. Отклонение
меньше 8 px не считается вовсе — иначе дрожь пальца дёргала бы героя.

### Что пришлось поправить в остальной игре

- `touch-action: none` на холсте. Без него браузер считает ведение пальца
  прокруткой страницы и забирает касание себе — стик срывается на первом же
  движении.
- Панели меню, инвентаря и лавки имели жёсткую ширину до 860 px и на телефоне
  вылезали за край вместе с кнопками. Ширина переехала в переменную `--w`,
  которую медиазапрос обнуляет.
- Кнопка «Закрыть» лежит в подвале панели, а подвал на коротком экране уезжает
  вниз: инвентарь **открывался и не закрывался**. Добавлен крестик на оверлее —
  оверлей не прокручивается, поэтому крестик виден всегда.
- Подсказка по клавишам на первом этаже заменена на подсказку по касаниям.
- В портрете игра просит повернуть телефон: поле 1024×640 в вертикальной
  полоске нечитаемо.

## 3. Сборка APK

Собрать APK **в этом окружении нельзя**: Android SDK не установлен, а
`dl.google.com` закрыт сетевой политикой. Команды ниже написаны по документации
и здесь не прогонялись — в отличие от всего остального в этом файле. Выполнять
их надо на своей машине.

Понадобится JDK 17+ и Android SDK (проще всего — установить Android Studio,
он тянет SDK сам).

### Вариант A: Capacitor — **для обычного APK**

Кладёт игру внутрь приложения. Хостинг не нужен, офлайн работает сразу,
файл можно просто переслать и установить.

```bash
npm init -y
npm i -D @capacitor/core @capacitor/cli @capacitor/android

node tools/make-webdir.js          # собирает www/ — 1.1 МБ, только нужные файлы
npx cap init "Тени Подгорья" com.example.undermountain --web-dir=www
npx cap add android
npx cap sync android

cd android && ./gradlew assembleDebug
# android/app/build/outputs/apk/debug/app-debug.apk
```

`tools/make-webdir.js` переносит `index.html`, `css/`, `js/`, `assets/` и
манифест, выбрасывая `.git`, `node_modules`, `tests` и `tools`, и заодно
вырезает регистрацию service worker: внутри WebView всё локальное, а лишний
слой кэша только помешает обновиться вместе с приложением.

Иконки приложения — `assets/icons/`, их рисует `node tools/make-icons.js`.
Android ждёт их в `android/app/src/main/res/mipmap-*`; проще всего положить
через Android Studio (*Image Asset* → *Launcher Icons*, взять
`icon-maskable-512.png`).

Чтобы приложение не крутилось при повороте, в
`android/app/src/main/AndroidManifest.xml` у активности:

```xml
android:screenOrientation="sensorLandscape"
```

Для установки на чужой телефон нужен релизный подписанный APK
(`./gradlew assembleRelease` со своим keystore); отладочный ставится только
с включённой установкой из неизвестных источников.

### Вариант B: Bubblewrap / TWA — для публикации в Google Play

Оборачивает **размещённую в сети** PWA. Приложение открывает ваш сайт в
доверенной вкладке Chrome — [быстрее обычного WebView примерно на
20%](https://www.flex.com.ph/articles/bubblewrap-vs-capacitor-my-2-year-test-results),
а обновления выкатываются с сайта, без нового APK.

```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://ваш-домен/manifest.webmanifest
bubblewrap build
```

Требует своего домена с HTTPS и файла `.well-known/assetlinks.json` на нём —
иначе Android покажет адресную строку поверх игры. Годится, когда игра и так
живёт на сайте, и не годится, когда нужен просто файл, который можно передать.

### Что выбрать

Нужен файл, который отправляешь другу, — **Capacitor**. Планируете Google Play
и у вас уже есть домен — **Bubblewrap**. Для одиночной игры, которую вы сейчас
делаете, первое.

## 4. Что осталось

По убыванию заметности для игрока:

1. **Звука по-прежнему нет.** На телефоне это заметнее, чем на компьютере:
   там играют в тишине или в наушниках, и немая игра кажется сломанной.
   Отдельно: браузеры не дают запустить звук до первого касания — заводить
   `AudioContext` надо в обработчике первого нажатия, иначе он останется
   заглушённым.
2. **Поле зрения не меняется.** 1024×640 — это 1.6:1, а телефон 2.16:1, поэтому
   по бокам чёрные поля примерно на четверть ширины. Лечится не растяжкой, а
   переменными `VIEW_W`/`VIEW_H`, но они зашиты в раскладку HUD в `render.js`,
   и это отдельная работа.
3. **Производительность не мерялась.** Проверки шли в headless-Chromium на
   настольной машине. Пол печётся в отдельный холст (`bakeFloorLayer`), так что
   тяжёлого в кадре мало, но на дешёвом телефоне это надо мерить, а не
   предполагать.
4. **Вибрация.** `navigator.vibrate(10)` на попадании — минута работы и
   заметная прибавка к ощущению удара.
5. **Полноэкранный режим во вкладке.** В установленной PWA он приходит из
   манифеста, а в обычной вкладке остаётся адресная строка. Лечится
   `requestFullscreen()` по первому касанию.

## Проверки

```
node tests/run.js       # данные и генерация, без браузера
node tests/browser.js   # сенсор, вёрстка под телефон, PWA — нужен playwright
node tests/combat.js    # бой, движение, лут — нужен playwright
```

Второй сам поднимает `tools/server.js`, эмулирует телефон 844×390 в ландшафте с
касаниями и проверяет стик, атаку удержанием, умения, открытие и закрытие
инвентаря, автоприцел, манифест, иконки и регистрацию service worker. Без
установленного playwright он молча выходит с нулевым кодом.

```
npm i playwright && npx playwright install chromium
```
