# Wharf enemy sprites

`assets/v27/wharf/wharf-mobs.png` is a 2048 × 1536 transparent RGBA sheet made from generated painted sprite pixels. It has 3 rows (`wharf_crab`, `wharf_harpooner`, `wharf_foreman`) and 4 poses per row (`idle`, `walk`, `attack`, `cast`). No sprite is drawn by replacement code. The shipwreck-wharf concept at `/workspace/scratch/513c16890429/generated_images/exec-e8eccea2-da7d-4d72-b3f0-12e8b2ca830c.png` supplied art direction; generated originals are `/workspace/scratch/513c16890429/generated_images/exec-ff277abc-5e10-4866-a68f-b8a73beda8c3.png` and the transparent extraction `/workspace/scratch/513c16890429/generated_images/exec-55a31122-9c47-4a00-be52-eeac99f8520f.png`.

`assets/v27/wharf/mob-frames.json` lists fixed 512 × 512 source frames. All four poses of a creature use one display size and one footline (cell-local y = 481); use `renderHeight` for the **whole** frame, and `anchor: [0.5, 0.94]`. `height` specifies the approximate visible height of the idle ink. The separately measured `inkBounds` are the actual alpha silhouettes, not interchangeable source frames: the original generator placed different poses at uneven offsets, and some original rectangles overlapped. Every frame has transparent edges and no adjacent silhouette pixels. `inkBounds` were computed after repacking with alpha threshold ≥16; the sheet alpha extrema are 0–255.

The sprites are four distinct static poses, **not** multiple animation frames for each state. Some orange/red color fringes from the extraction remain at high zoom, mainly on the boss; at game scale they are less conspicuous. Cast poses are wind-ups without a separate projectile or particle effect. The visual light comes from upper left and all feet share a local row baseline. No code integration is made here.
