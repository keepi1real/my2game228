Главный инженер: самостоятельная команда в `team-wharf`, ветка `codex/v27-wharf`.
Задача — новая игровая глава `drownedwharf`, 16 комнат, совместимый контракт героя,
честная геометрия сухого пола, два врага и босс с авторским растровым артом.
Работа ограничена файлами `v27-wharf-*`, `assets/v27/wharf`, `docs/v27/wharf`.

## Инженерные решения

- Уровень регистрируется общим build-time расширением root до freeze реестров.
- JSON `shape` переопределяется RoomCraft; runtime после create применяет
  детерминированные `deckSize`/`deckProfile` к фактическим polygon коллизиям.
- Изменён только уникальный level ID: повторная загрузка строит ту же геометрию.
- Ground hook заменяет старые каменные борта только на верфи. Все сухие области
  рисуются по тому же union полигонов, который использует mapFor.
- Растры грузятся при первой отрисовке главы, не в меню. Прозрачность укрытий
  сохраняет читаемость героя; Y sorting остаётся штатным.

## Ограничение потока специалистов

После двух отдельных специалистов tool `spawn_agent(combat_director)` отклонил
создание: `agent thread limit reached`. По решению root новые ролевые задания
выполняются последовательными followup в существующих потоках. Художник мобов
получил отдельное задание режиссёра боя; это две роли в одном Sol-потоке, а не
двое одновременно работающих специалистов. Ограничение модели/слотов
отражено в этом журнале, без выдуманных параллельных участников.

## Интеграция антикайта

После замечания root главный инженер добавил крабу предупреждённый физический
рывок и увеличил до 470 длину полосы гарпунщика (начало прицеливания до 430).
Рывок использует штатные moveEntity, коллизию, stun/knockback и сохранение charge.
Аудит QA проводится после этой правки; не заявляется гарантия от любого кайта.
Финальные raster-файлы просмотрены главным инженером отдельно и в настоящем
Canvas-сценарии с двумя живыми врагами. Для поднятой клешни bodyTop учитывает
фактическую границу cast-кадра, не накладывая HP-индикатор поверх инструмента.

## Финальный gate

`node tools/test-v27-wharf.cjs` повторён lead: PASS. Включены три seed, пять
героев, PNG/12 кадров, реальный rush 210 px и остановка у стены на 50 px,
mid-warning/mid-charge сохранения, идентичная геометрия, phase-II босса и
пиксельная проверка union при обратном winding коридора. Финальный кадр
проверен после исправления некорректной тестовой постановки героя за стеной.
Браузерный input smoke, полный проход и длительный баланс остаются общим
приёмочным этапом root. Локальная поставка не публикует и не отправляет ветку.
