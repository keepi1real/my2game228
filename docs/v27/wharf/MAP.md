# Верфь утонувшего света — карта и атлас

`tools/v27-wharf-level.json` задаёт `drownedwharf`, этаж 12, 16 комнат, финал в комнате 15. Возможные старты движка — 0, 5, 10. Комнаты лежат на сетке 4 × 4 с шагом `[1060,700]`; сухие площадки имеют разные половинные размеры `deckSize` от `[468,278]` до `[570,354]`. Профили `shoal` (неровная отмель), `slipway` (вытянутый стапель) и `drydock` (широкая ремонтная площадка) обрабатываются runtime **после** `RoomCraft.reshape`, который иначе заменяет исходный `shape`. Старые значения `shape` оставлены только совместимыми метками для штатного конструктора. Каждая площадка расширяет центральный старый envelope 450 × 262; не вырезать пол под уже размещёнными объектами и reward sockets.

Центры вычисляются формулой runtime `(640 + x·1060, 493 + (y+1)·700)`. Самый правый край `3820+570=4390 < 4736`; нижний `3293+354=3647 < 4032`. Рёбра `edges` соединяют только соседние центры. Между берегами проходят короткие сухие мостки с половинной шириной 112–128 в runtime; `passageFlare:116` остаётся совместимым базовым параметром. Дополнительные рёбра дают обходы, но последний вход к боссу только `14→15` — соседняя на сетке площадка 8 к нему не соединена. Вода видна *за пределом* геометрии и не является проходом; вдоль каждого полигона нужен ясный светлый влажный срез и контактная тень со стороны воды, без нарисованных внутренних провалов. Рёбра керамических корпусов и лебёдки ставятся только на реальные `obstacles` с совпадающей опорой; центр для боя остаётся тихим.

Три props занимают **неравные** области; равные колонки 724 px режут лебёдку и ребро. Приведённые source rectangles охватывают раздельные alpha-компоненты с 6 px полем. Для floor выбирать **один** внутренний квадрат и clip к площадке/коридору, а не повторять весь лист сразу. Материалы авторские, не гарантированно бесшовные: уменьшенный фрагмент и/или спокойное перекрытие швов вместо крупного бесконтрольного тайлинга. Для props использовать исходный alpha и привязать низ изображения к `o.x,o.y`, масштабировать по `o.r`/`o.height`, не запекать круг тени. В JSON стоят зарегистрированные `tidepillar/tidebasin/tidewall` до переобозначения уже созданных препятствий runtime в `wharf_hull/wharf_winch/wharf_piles`; новые имена — атласные hooks, не новые типы коллизий. Врагами уровня указаны только `wharf_crab`, `wharf_harpooner`, босс `wharf_foreman`.

Существующие растры как fallback/дополнительная спокойная фактура: `assets/tiles/floor_plain.webp`, `assets/tiles/floor_grit.webp`, `assets/tiles/floor_crack.webp`, `assets/tiles/wall_tileset.webp`, `assets/v20/ceramic-observatory-floor.png`, `assets/crown-v11/glass-terrain.png`, `assets/crown-v11/amber-terrain.png`, `assets/crown-v11/glass-atlas.png`, `assets/crown-v11/amber-atlas.png`. Их дворцовые силуэты не использовать вместо новой верфи.
