# Бой в Тёмном Корне

Модуль `tools/v27-darkroot-combat.js` ставится после runtime Darkroot и существующего RootCombat. Он работает только при `journey.seamless && journey.levelId === 'darkroot'` с `root_reaper`, `root_grafter`, `root_heart`. Для остальных актёров каждый обёрнутый метод передаёт вызов прежнему методу ровно один раз. Runtime регистрирует этих актёров; модуль боя не меняет реестр, масштабирование этажа или структуру сохранения.

| Противник | Подготовка и опасная область | Контригра |
| --- | --- | --- |
| Корневой косарь | Сектор радиусом 133, угол ±1.13, зафиксирован при начале замаха. На расстоянии 174–375 готовит рывок 0.9 с; полоса 250 px покрывает 210 px движения и радиусы столкновения. | Обойти сектор или выйти из заранее отмеченной полосы; между атаками он ускоренно сокращает дистанцию. |
| Прививочник | На текущем месте героя фиксирует круг радиусом 61 с предупреждением 1.2 с; после раскрытия он остаётся на 2.45 с. | Уйти с отметки; на близкой дистанции враг отступает, на средней смещается к герою и может быть настигнут ближним бойцом. |
| Сердцевик | Кольцо с безопасным центром (inner 87/94), фиксированный круг у героя (67/76), две расходящиеся полосы; во второй фазе три полосы с промежутками. Базовый сектор 128. | Центр кольца, выход из круга и промежутки между полосами доступны в заявленной геометрии. После раскрытия есть 1.85–2.05 с восстановления для ответной атаки ближних героев. |

Фаза 2 начинается при ≤50% здоровья. Начальные интервалы способностей босса заданы в `bossDef`: `pulse=6.8`, `graft=9.2`, `rootlane=7.6`. Все зоны и точка прицеливания фиксируются при начале предупреждения; разрешение удара проверяет те же `shapes` через `RootCombat.canDamage`. Допустимые виды сохранённого предупреждения: `sweep`, `spores`, `lunge`, `toll`, `bolts`, `mirror-lanes`. Признак `v27Darkroot` находится внутри существующего `telegraph`; таймер рывка Косаря и способности босса — внутри `abilityTimers`. Фазы, заряд и восстановление используют штатные поля `phase`, `charge`, `rootRecovery`. Новых ключей checkpoint нет.
