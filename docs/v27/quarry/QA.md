# Красный карьер — проверка кандидата

Проверено 27 сентября 2026 в `team-quarry` на настоящем JS игрового движка через Node VM и Canvas. Команды:

```sh
node tools/test-v27-quarry-route.cjs
node tools/test-v27-quarry-art.cjs
node tools/test-v27-quarry-combat.cjs
```

Все три команды завершились с кодом 0.

| Проверка | Фактический результат |
| --- | --- |
| Геометрия | Три seed `42`, `731`, `987654321`; BFS с радиусом героя 12 px и шагом 16 px на реальном `map.circleBlocked`. Достижимы центры всех 16 комнат, точки входов 0/5/10, подход к выходу босса, награды и три сечения каждого из 22 проходов. Достижимые/проходимые ячейки: 18115/18122, 18181/18202, 17984/18005. |
| Сохранение | Для каждого seed повторный `saveJourney` → `resumeSeamlessJourney` дал точное JSON-совпадение room polygons, corridor polygons и obstacles; значения параметров врагов конечны. Проверен standalone difficulty rank 1. |
| Арт персонажей | Реальные raster-атласы загружены; у всех 36 кадров трёх персонажей нижняя альфа-строка одинаковая (185), renderer возвращает native sprite width для тени, Canvas transform и alpha восстановлены после отрисовки. Кадр `assets/v27/quarry/qa-actor-grounding.png`: стопы, силуэты и тени визуально согласованы. |
| Бой | Реальные basic и boss вызовы: сектор тесака, неподвижная дальняя метка, отмена при закрытой LOS, запрет старта атаки в неактивной комнате, переход босса во вторую фазу, три полосы реза, collision-aware рывок без повторного урона, четыре сохранения во время телеграфов и делегирование старого биома. Кадр `assets/v27/quarry/qa-boss-warning.png`: оба круга телеграфа читаются поверх глины; фарфоровые прожилки находятся сбоку и не выглядят границей опасной зоны. |

На контрольном кадре крупные камни имеют контактные тени, и видимая скальная кромка совпадает с краем игрового пола; явной ложной стены или срезанного персонажа не видно. Это визуальная проверка выбранных кадров, не доказательство каждой точки карты.

Ограничения: тесты не заменяют полный ручной браузерный забег, touch-управление, человеческую оценку сложности, сетевой hosting smoke и проверку всех возможных seed. Скриншот боя показывает standalone интерфейс `ЭТАЖ 1 / Глава 1/10`, хотя registry level metadata содержит `floor: 13`; перед выпуском нужно согласовать эту подпись с режимом отдельной главы.
