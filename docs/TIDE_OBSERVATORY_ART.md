# Обсерватория прилива — материалы и визуальная проверка

## Исправление отрисовки

Прежний слой `v21-tide-observatory-art.js` закрывал расписанный каменный пол непрозрачной синей заливкой только внутри комнат. Коридоры сохраняли исходную фактуру; их стыки резко отличались. Нарисованные колонны, чаши и архивы были заменены простыми геометрическими корпусами. Это создавало заметный разрыв качества с героем и расписанным фоном.

Теперь комнаты **и коридоры** получают одну поверхность из существующего каменного атласа `assets/recovered-v9/5003907889809929.png`. В нём сохранены фаски, неровные швы, сколы и трещины. Слабая бирюзовая глазурь связывает камень с палитрой обсерватории, сохраняя его детали. Материал создаётся один раз в отдельном canvas; CanvasPattern кэшируется для каждого контекста.

Изометрическое преобразование материала привязано к мировым координатам. Все полигоны видимых комнат и переходов образуют один clip и получают одну заливку: повторное перекрытие входа не меняет цвет, а камера не сдвигает плитку. Обводится только настоящий наружный контур `map.boundary`, рассчитанный движком по объединённой геометрии. У проёмов нет нарисованных поперечных стен и закрытых порогов. При ещё не загруженном атласе остаётся исходный пол с лёгкой глазурью, а не сплошной заменяющий прямоугольник.

Латунные детали ограничены двумя небольшими ремонтными скобами и потёртым открытым измерительным сектором у края каждой комнаты. Число рисок соответствует роли. Центральная зона свободна от крупных панелей, логотипов и замкнутых колец. Текстура камня обеспечивает детализацию без дополнительных препятствий.

## Объекты и прозрачность

Используется исходный расписанный `tideSheet`:

| Sprite | Исходный рисунок |
|---|---|
| `tidepillar` | Светлая каменная колонна с латунью и патиной |
| `tidebasin` | Каменно-латунная бирюзовая чаша |
| `tidescholar` | Каменная статуя наблюдателя |
| `tideshelves` | Архив с книгами, резьбой и металлическими деталями |
| `tidewall` | Низкая каменная балюстрада |

`landmark-v15-tideobservatory`, созданный RoomCraft, восстанавливается по `homeRoom` и `room.design.landmark` через поверхностную копию объекта только для отрисовки. Нативные объекты передаются исходному renderer напрямую. Коллизии, размещение, исходные высоты объектов и сохранения не изменяются. Действуют исходные тени и прозрачность при перекрытии героя. Сглаживание расписанных атласов включается локально; состояние canvas восстанавливается после вызова.

## Интеграция и проверки

Модуль устанавливается после `v20-matte-floor.js`, до `v20-combat-visibility.js`; действует только при `journey.v21MapVersion === 21` в биоме `tideobservatory`. Другие биомы и сохранения v20 используют прежнюю отрисовку. Геометрия, маршруты, игровые случайные числа и механики босса не меняются.

`node tools/test-v21-tide-observatory-art.cjs` использует настоящий Canvas и загружает настоящие PNG атласов. Проверяет:

- пиксельно одинаковый материал на стыках комнаты/коридора и на непрерывном полу;
- отсутствие заливки вне объединения полигонов;
- неизменность мировых координат текстуры при движении камеры (допуск 2/255 для округления растеризатора);
- детерминированную отрисовку и однократное создание материала;
- передачу четырёх семейств нативных/алиасных объектов исходному renderer;
- сохранение прозрачности, canvas state, фильтрацию версии и области камеры;
- отсутствие изменения игровых данных и использования игрового RNG.

Визуальная проверка проводится отдельно полным renderer игры с загруженными изображениями. Контактный лист `tide-after-contact.png` включает вход, двор шлюзов, архив, отдых, арену и середину перехода между входом и двором. Кадры снимаются из отдельных PNG-буферов, сохраняют соотношение 1024:640 и используют фактический `journey.current`. Дополнительно проверяются настоящий телеграф «Нулевого меридиана» и прозрачность колонны перед героем. Автоматический тест материала не заменяет эту оценку игровых кадров.
