# Фоны экранов интерфейса

Сюда кладутся фоновые изображения DOM-экранов (меню, выбор героя, лагерь).

| файл | размер | формат | где используется |
|---|---|---|---|
| `menu_bg.webp` | 1600×900 | WebP | `.overlay-front` в `css/style.css` |

Файл подключается сам: путь уже прописан в стилях, а `tools/bundle.js` вшивает его
в `dist/index.html` как data URI. Отдельно ничего править не нужно.

Если файла нет, страница остаётся рабочей: не загрузится только картинка, а
затемняющий градиент над ней никуда не денется.
