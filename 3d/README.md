# Архив: вид сверху под углом

Замороженная копия версии с квадратной сеткой и видом сверху под небольшим
наклоном — той, что была в корне до перехода на изометрию.

Открывается двойным кликом по `3d/index.html`. Копия самодостаточная: свои
`css/`, `js/` и `assets/`, наружу ничего не тянет. Правки сюда не вносятся —
папка нужна как ориентир, чтобы было с чем сравнивать новый рендер.

Прогресс хранится в `localStorage` и общий с основной версией, если обе
открыты с одного адреса.
