# Тени Подгорья

Браузерный rogue-like в реальном времени о героях в духе Средиземья, спускающихся в подземелье под горами.

## Запуск

### Обычный способ — двойной клик

Откройте `index.html` двойным кликом. Сборка и сервер не нужны: в коде нет ни
ES-модулей, ни `fetch`, ни чтения пикселей с холста — то есть ничего из того,
что браузер запрещает по протоколу `file://`.

Прогресс (уровни героев, осколки, улучшения) хранится в `localStorage`. У
`file://` и у `http://localhost` хранилища разные, поэтому при смене способа
запуска прогресс будет свой.

### Автономный файл

`dist/index.html` — вся игра в одном файле: скрипты, стили и картинки вшиты
как data URI. Рядом ничего лежать не должно. Удобно переслать или выложить.

Пересобрать после правок в `js/`, `css/` или `assets/`:

```
node tools/bundle.js
```

Файл лежит в `.gitignore`: он весит больше мегабайта и переписывался бы
целиком на каждый коммит.

### Локальный сервер

Нужен только при работе над кодом — чтобы F5 подхватывал правки без возни
с кэшем. На геймплей не влияет.

```
python3 -m http.server 8123
```

Дальше откройте <http://localhost:8123>.

Тот же результат без Python даёт `node tools/server.js [порт]`: он раздаёт папку
игры по HTTP и печатает адрес, по которому её видно с других компьютеров сети.

Внутри у него есть и вторая половина — WebSocket-релей, пересылающий сообщения
между двумя подключившимися браузерами. Игрового кода, который бы им пользовался,
пока нет: это задел под кооператив на двоих, и на одиночную игру он никак не влияет.

### Проверка логики без браузера

```
node tests/run.js
```

Печатает «Все проверки пройдены», если всё в порядке.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел |
| ЛКМ / Пробел | атака |
| 1 2 3 | умения героя |
| Shift | уклонение (неуязвимость) |
| F / G / R / T | зелье / хлеб / свиток пламени / эликсир |
| I / Tab | инвентарь |
| E | торговец |
| Esc | пауза |

## Что внутри

- 5 героев со своими статами и тремя умениями каждый: Аратор (следопыт), Балдин (гном), Фаелас (эльф-лучник), Митрандир (маг), Перегрин (хоббит). Трое открываются за осколки.
- 10 процедурно сгенерированных этажей, боссы на 5-м и 10-м, торговцы на 3-м и 7-м.
- 9 видов монстров с разным ИИ (ближний бой, лучники, яд, замедление), два босса с телеграфируемыми способностями и второй фазой.
- Предметы трёх редкостей с аффиксами, три слота экипировки, сумка на 12 ячеек, расходники, сундуки.
- Уровень героя сохраняется навсегда. Смерть отнимает только вещи и золото.
- Мета-прогресс: осколки мифрила → новые герои, 9 постоянных улучшений, стартовые предметы.

## Визуальные ассеты

Слой `js/visual-assets.js` решает, чем нарисовать существо. Порядок выбора:

1. **спрайт** — вырезанный персонаж с альфа-каналом, стоит ступнями на игровой координате;
2. **портрет** — живописная иллюстрация с фоном, показывается круглым токеном;
3. **фигура** — геометрический фолбэк из `render.js`.

Любое звено можно оставить пустым: рендер спустится к следующему, поэтому незаконченный набор
арта не ломает игру. Боевая логика в этом слое не участвует.

### Спрайты

Формат: WebP 256×256 с альфа-каналом, персонаж по центру, ступни у нижнего края. Чтобы
подключить спрайт, положите файл в `assets/sprites/` и добавьте строку в `SPRITES` с id из
`js/data.js`:

```js
goblin: { src: 'assets/sprites/goblin.webp', anchorY: 0.973, height: 48 },
```

`anchorY` — доля высоты исходника, на которой находятся ступни; `height` — высота фигуры на
экране. Рост задан по природе персонажа: эльф 58, человек 56, гном 46, хоббит 42, тролль 88.

Спрайты анимируются процедурно, без дополнительных кадров: шаг при ходьбе, наклон в сторону
бега, дыхание в покое, выпад при атаке, дрожь при оглушении, вспышка при попадании и
зеркалирование по направлению взгляда.

#### Как они сделаны

Персонажи на живописных иллюстрациях уже стоят в полный рост лицом к зрителю — это ровно та
поза, которая нужна спрайту, поэтому спрайты не рисовались заново, а вырезаны из портретов:

```
pip install pillow rembg onnxruntime
python3 tools/make-sprites.py            # всю партию
python3 tools/make-sprites.py goblin     # только одного
```

Скрипт снимает фон нейросетевой сегментацией, поднимает тени (живописные фигуры слишком
тёмные для мелкого размера), добавляет контровой свет по верхне-левому краю и ставит фигуру
ступнями к нижнему краю холста. Контровой свет обязателен: без светлой каймы тёмный силуэт
сливается с тёмным полом подземелья. Скрипт печатает готовую строку для `SPRITES`.

### Тайлы пола

В `assets/tiles/` лежат четыре бесшовные каменные текстуры 256×256. `floor_plain` заливает весь
проходимый пол, остальные три ложатся поверх редкими пятнами с мягким краем.

Весь пол со стенами печётся один раз при загрузке этажа в отдельный холст (`bakeFloorLayer`), и
каждый кадр из него берётся только видимый кусок одним `drawImage` вместо тысяч заливок по
тайлам. Раскладка пятен детерминирована: сид считается из размеров карты и центров комнат,
поэтому один и тот же этаж всегда выглядит одинаково. Запекание занимает около 16 мс и
приходится на затемнение при переходе между этажами.

Лестница в слой не попадает — её вид меняется по ходу боя с боссом, поэтому она рисуется
каждый кадр. Туман войны тоже накладывается поверх слоя покадрово.

Если текстуры ещё не загрузились, `bakeFloorLayer` возвращает `null`, и `drawMap` рисует пол
прежней заливкой, повторяя попытку на следующем кадре.

### Портреты

Иллюстрации с фоном в `assets/heroes/` и `assets/enemies/`. Их основное место — меню и карточки
выбора героя. Кроп токена задаётся в `PORTRAITS`: `focusX`/`focusY` — точка исходника, которая
попадёт в центр токена, `zoom` — во сколько раз вырезаемый квадрат меньше короткой стороны.

Спрайты и портреты есть у пяти героев, гоблина, варга, паука и тролля. Орк, лучник, урук,
умертвие, тень и оба босса пока рисуются геометрическими фигурами — для них нет исходных
иллюстраций.

## Структура

```
index.html      разметка и подключение скриптов
css/style.css   стили DOM-меню
css/visual-assets.css  стили портретов в меню и карточках
assets/tiles/   бесшовные текстуры пола
js/utils.js     RNG, математика, линия видимости
js/data.js      герои, умения, монстры, боссы, предметы, улучшения
js/save.js      сохранение прогресса
js/dungeon.js   генерация этажей, туман войны, поле путей
js/entities.js  игрок, враги, снаряды, лут, генерация предметов
js/game.js      ввод, игровой цикл, бой, ИИ, инвентарь
js/render.js    отрисовка карты, сущностей и HUD
js/ui.js        DOM-экраны: меню, лагерь, инвентарь, торговец
js/visual-assets.js  спрайты, портреты и процедурная анимация
js/main.js      точка входа
tests/run.js    проверки данных и генерации без браузера
tests/fixtures/ тестовый спрайт для проверки отрисовки
tools/bundle.js сборка в один файл
tools/server.js раздача игры по локальной сети
tools/make-sprites.py  нарезка спрайтов из портретов
```

Единственный источник правды о том, какой файл к какому существу относится, —
`js/visual-assets.js`. Отдельного манифеста ассетов нет: он дублировал бы эти
таблицы и расходился бы с ними.

## Сборка в один файл

```
node tools/bundle.js
```

Создаёт `dist/index.html` — автономную страницу со встроенными стилями, скриптами и ассетами
(WebP вшиваются как data URI), которую удобно отправить или выложить куда угодно.

`dist/` намеренно не в репозитории. Файл содержит все ассеты в base64 и переписывался бы целиком
на каждый коммит: в истории он уже занимал 3.1 МБ против 0.6 МБ всего арта. Сборка занимает
доли секунды, поэтому хранить её нет смысла.
