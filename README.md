# Тени Подгорья

Браузерный rogue-like в реальном времени о героях в духе Средиземья, спускающихся в подземелье под горами.

## Запуск

Откройте `index.html` в браузере — сборка и сервер не нужны. Прогресс сохраняется в `localStorage`.

Для проверки логики без браузера:

```
node tests/run.js
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел |
| ЛКМ / Пробел | атака |
| 1 2 3 | умения героя |
| Shift | уклонение (неуязвимость) |
| F / G / R / T | зелье / хлеб / свиток пламени / эликсир |
| I / Tab | инвентарь |
| E | торговец |
| Esc | пауза |

## Что внутри

- 5 героев со своими статами и тремя умениями каждый: Аратор (следопыт), Балдин (гном), Фаелас (эльф-лучник), Митрандир (маг), Перегрин (хоббит). Трое открываются за осколки.
- 10 процедурно сгенерированных этажей, боссы на 5-м и 10-м, торговцы на 3-м и 7-м.
- 9 видов монстров с разным ИИ (ближний бой, лучники, яд, замедление), два босса с телеграфируемыми способностями и второй фазой.
- Предметы трёх редкостей с аффиксами, три слота экипировки, сумка на 12 ячеек, расходники, сундуки.
- Уровень героя сохраняется навсегда. Смерть отнимает только вещи и золото.
- Мета-прогресс: осколки мифрила → новые герои, 9 постоянных улучшений, стартовые предметы.

## Визуальные ассеты

Слой `js/visual-assets.js` решает, чем нарисовать существо. Порядок выбора:

1. **спрайт** — вырезанный персонаж с альфа-каналом, стоит ступнями на игровой координате;
2. **портрет** — живописная иллюстрация с фоном, показывается круглым токеном;
3. **фигура** — геометрический фолбэк из `render.js`.

Любое звено можно оставить пустым: рендер спустится к следующему, поэтому незаконченный набор
арта не ломает игру. Боевая логика в этом слое не участвует.

### Спрайты

Формат: WebP 256×256 с альфа-каналом, персонаж по центру, ступни у нижнего края. Чтобы
подключить спрайт, положите файл в `assets/sprites/` и добавьте строку в `SPRITES` с id из
`js/data.js`:

```js
goblin: { src: 'assets/sprites/goblin.webp', anchorY: 0.973, height: 48 },
```

`anchorY` — доля высоты исходника, на которой находятся ступни; `height` — высота фигуры на
экране. Рост задан по природе персонажа: эльф 58, человек 56, гном 46, хоббит 42, тролль 88.

Спрайты анимируются процедурно, без дополнительных кадров: шаг при ходьбе, наклон в сторону
бега, дыхание в покое, выпад при атаке, дрожь при оглушении, вспышка при попадании и
зеркалирование по направлению взгляда.

#### Как они сделаны

Часть спрайтов вырезана из живописных портретов: персонажи там уже стоят в полный рост
лицом к зрителю, то есть ровно в позе, которая нужна спрайту.

```
pip install pillow rembg onnxruntime
python3 tools/make-sprites.py            # всю партию
python3 tools/make-sprites.py goblin     # только одного
```

Скрипт снимает фон нейросетевой сегментацией, поднимает тени, добавляет контровой свет
и ставит фигуру ступнями к нижнему краю холста.

Присланные готовые вырезы обрабатывает другой скрипт — сегментация им не нужна, зато в
исходниках попадается запечённый фон: ровная серая заливка, отрисованная шахматка
прозрачности, полупрозрачная дымка и россыпь непрозрачных блоков-ошмётков. Дымка опаснее
всего: сама по себе она почти не видна, но раздувает габариты, и существо после
кадрирования масштабируется мельче, чем должно.

```
pip install pillow scipy
python3 tools/make-mob-sprites.py путь/к/файлу.webp uruk 60
```

Оба скрипта печатают готовую строку для `SPRITES`.

### Портреты

Иллюстрации с фоном в `assets/heroes/` и `assets/enemies/`. Их основное место — меню и карточки
выбора героя. Кроп токена задаётся в `PORTRAITS`: `focusX`/`focusY` — точка исходника, которая
попадёт в центр токена, `zoom` — во сколько раз вырезаемый квадрат меньше короткой стороны.

Спрайты есть у всех пяти героев, у десяти из двенадцати монстров, у первого босса Гразгота,
а также у торговца и лестницы. Портреты для меню есть у героев, гоблина, варга, паука и тролля.

Без арта остались орк, тень и финальный босс Моргул — они рисуются геометрическими фигурами.
У существ со спрайтом ореол босса и телеграф замаха ложатся пятном на пол, а не повторяют
силуэт фигуры.

### Реквизит

`assets/props/` — не существа, а объекты на карте. Таблица `PROPS` в `js/visual-assets.js`
устроена как `SPRITES`, но понимает флаг `flat`: с ним картинка центрируется на точке, а не
ставится на неё ступнями. Торговец стоит, лестница лежит на полу. Пока босс жив, лестница
гасится и поверх неё рисуется крест.

## Структура

```
index.html      разметка и подключение скриптов
css/style.css   стили DOM-меню
css/visual-assets.css  стили портретов в меню и карточках
assets/tiles/   бесшовные текстуры пола
js/utils.js     RNG, математика, линия видимости
js/data.js      герои, умения, монстры, боссы, предметы, улучшения
js/save.js      сохранение прогресса
js/dungeon.js   генерация этажей, туман войны, поле путей
js/entities.js  игрок, враги, снаряды, лут, генерация предметов
js/game.js      ввод, игровой цикл, бой, ИИ, инвентарь
js/render.js    отрисовка карты, сущностей и HUD
js/ui.js        DOM-экраны: меню, лагерь, инвентарь, торговец
js/visual-assets.js  спрайты, портреты и процедурная анимация
js/main.js      точка входа
tests/run.js    проверки данных и генерации без браузера
tests/fixtures/ тестовый спрайт для проверки отрисовки
```

## Сборка в один файл

```
node tools/bundle.js
```

Создаёт `dist/index.html` — автономную страницу со встроенными стилями, скриптами и ассетами
(WebP вшиваются как data URI), которую удобно отправить или выложить куда угодно.

`dist/` намеренно не в репозитории. Файл содержит все ассеты в base64 и переписывался бы целиком
на каждый коммит: в истории он уже занимал 3.1 МБ против 0.6 МБ всего арта. Сборка занимает
доли секунды, поэтому хранить её нет смысла.
