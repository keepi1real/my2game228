# Тени Подгорья

Браузерный rogue-like в реальном времени о героях в духе Средиземья, спускающихся в подземелье под горами.

## Запуск

Откройте `index.html` в браузере — сборка и сервер не нужны. Прогресс сохраняется в `localStorage`.

Для проверки логики без браузера:

```
node tests/run.js
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел |
| ЛКМ / Пробел | атака |
| 1 2 3 | умения героя |
| Shift | уклонение (неуязвимость) |
| F / G / R / T | зелье / хлеб / свиток пламени / эликсир |
| I / Tab | инвентарь |
| E | торговец |
| Esc | пауза |

## Что внутри

- 5 героев со своими статами и тремя умениями каждый: Аратор (следопыт), Балдин (гном), Фаелас (эльф-лучник), Митрандир (маг), Перегрин (хоббит). Трое открываются за осколки.
- 10 процедурно сгенерированных этажей, боссы на 5-м и 10-м, торговцы на 3-м и 7-м.
- 9 видов монстров с разным ИИ (ближний бой, лучники, яд, замедление), два босса с телеграфируемыми способностями и второй фазой.
- Предметы трёх редкостей с аффиксами, три слота экипировки, сумка на 12 ячеек, расходники, сундуки.
- Уровень героя сохраняется навсегда. Смерть отнимает только вещи и золото.
- Мета-прогресс: осколки мифрила → новые герои, 9 постоянных улучшений, стартовые предметы.

## Структура

```
index.html      разметка и подключение скриптов
css/style.css   стили DOM-меню
js/utils.js     RNG, математика, линия видимости
js/data.js      герои, умения, монстры, боссы, предметы, улучшения
js/save.js      сохранение прогресса
js/dungeon.js   генерация этажей, туман войны, поле путей
js/entities.js  игрок, враги, снаряды, лут, генерация предметов
js/game.js      ввод, игровой цикл, бой, ИИ, инвентарь
js/render.js    отрисовка карты, сущностей и HUD
js/ui.js        DOM-экраны: меню, лагерь, инвентарь, торговец
js/main.js      точка входа
tests/run.js    проверки данных и генерации без браузера
```
