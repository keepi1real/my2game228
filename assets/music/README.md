# Музыка

Пока папка пуста — игра синтезирует подложку на лету (`js/audio.js`, `Sound.moods`).
Любой положенный сюда файл автоматически вытесняет синтез: код трогать не нужно.

Формат: `mp3`, `ogg` или `wav`. Ищется в этом порядке, первый найденный выигрывает.
Длина 30–60 секунд, петля склеивается затуханием — идеально ровный луп не нужен.

| файл | когда играет |
|---|---|
| `undermountain.mp3` | этаж I · Подгорье |
| `eclipse.mp3` | этаж II · Обсерватория затмения |
| `rootvault.mp3` | этаж III · Багряный корнесвод |
| `storm.mp3` | этаж IV · Цитадель Белой Бури |
| `tide.mp3` | этаж V · Затопленные архивы |
| `sunforge.mp3` | этаж VI · Кузня Чёрного Солнца |
| `amber.mp3` | этаж VII · Янтарный некрополь |
| `glass.mp3` | этаж VIII · Сады Лунного Стекла |
| `combat_1.mp3` … `combat_3.mp3` | бой, трек выбирается по номеру этажа |
| `boss_1.mp3` | босс этажей I–VI |
| `boss_2.mp3` | босс этажей VII–VIII |
| `menu.mp3` | меню и экраны между походами |

Бой включается сразу, как противник заметил героя, и отпускает через четыре
секунды тишины. Переход всегда перекрёстным затуханием.
