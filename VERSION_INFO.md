# Версии игры

## Актуальная

`main` — **Экспедиция v11**. Это то, что открывается из `index.html`
и то, что публикуется на GitHub Pages:
https://keepi1real.github.io/my2game228/

## Архив

Всё остальное сведено в одно место — ветки с префиксом `archive/`:

| Ветка | Что это |
| --- | --- |
| `archive/legacy-pre-v11` | Старая версия — состояние `main` до v11 |
| `archive/iso-render` | Эксперимент: отрисовка в изометрии 2:1 |
| `archive/mobile-rogue` | Ранняя ветка сенсорного управления и адаптива |
| `archive/assets-audit` | Аудит ассетов: сортировка по глубине, отложенные сохранения |

Посмотреть любую из них, не трогая рабочую копию:

```
git switch --detach archive/legacy-pre-v11
```

Вернуться к актуальной версии:

```
git switch main
```
